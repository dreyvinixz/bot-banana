# 🛡️ Política de Segurança

## Versões Suportadas

Oferecemos atualizações de segurança para as seguintes versões:

| Versão | Suportada |
| ------ | ---------- |
| 1.0.x  | ✅ Sim     |
| < 1.0  | ❌ Não     |

## Reportando Vulnerabilidades

Levemos a segurança a sério. Se você descobrir uma vulnerabilidade de segurança no **BotBanana**, por favor **NÃO** abra uma issue pública.

Em vez disso, envie um e-mail de reporte para a equipe de manutenção ou abra uma divulgação privada de vulnerabilidades através da aba **Security** no repositório do GitHub.

### O que incluir no seu reporte:

- Uma descrição detalhada da vulnerabilidade.
- Passos para reproduzir o problema.
- Impacto em potencial e qualquer mitigação conhecida.

Agradecemos o seu esforço para proteger a comunidade!
